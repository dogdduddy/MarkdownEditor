# MD Lens

로컬 Markdown 파일을 Chrome에서 보기 좋게 렌더링하는 개인용 확장 프로그램(Manifest V3)입니다.
Finder에서 `.md` 파일을 Chrome으로 열면 목차·폴더 탐색이 붙은 뷰어로 표시됩니다.

## 설치

1. 이 저장소를 받습니다. `dist/` 폴더에 빌드된 확장이 들어 있습니다.
2. Chrome에서 `chrome://extensions` 를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다** → `dist` 폴더를 선택합니다.
4. MD Lens의 **세부정보**에서 **파일 URL에 대한 액세스 허용**을 켭니다. (로컬 파일 렌더링에 필수)
5. Finder에서 `.md` 파일 → 정보 가져오기 → "다음으로 열기"를 Chrome으로 지정하고 "모두 변경".

비슷한 Markdown 확장 프로그램이 이미 설치되어 있으면 둘이 같은 페이지를 동시에 바꾸려 하므로 한쪽은 꺼 두세요.

## 기능

**뷰어**
- 사이드바: 목차(스크롤 위치 추적, 접기) / 폴더 트리(하위 폴더 펼치기, 상위 폴더 이동) / 검색 필터, 너비 드래그 조절
- 메뉴: 원본 보기 전환, 전체 화면, 전망 모드, 인쇄, 설정
- 폴더 URL(`file:///…/폴더/`)을 파일 탐색 화면으로 렌더링
- 파일 변경 시 자동 새로 고침(0.5~600초), `.txt` 렌더링, 문자 집합 호환 모드
- `**동일 인물(1인칭)**로` 처럼 한글·괄호에 붙은 굵은 글씨가 깨지지 않도록 CJK 강조 규칙 적용

**외관**: 글꼴 크기·글꼴, 테마(자동/밝게/어둡게), 모드별 코드 블록 테마, 코드 줄바꿈, 표 가로 확장, 전망 모드, 중앙 정렬, 최대 콘텐츠 너비(px/%), 사용자 정의 CSS

**플러그인**(개별 on/off): 줄 바꿈, 링크 자동 인식, 타이포그래피, 이모지, 위/아래 첨자, `[[TOC]]`, 삽입 `++`, 강조 `==`, 수식(KaTeX), Mermaid, PlantUML, 약어, 정의 목록, 각주, 프론트 매터, Multi-Markdown 테이블, 작업 목록, 알림 블록

PlantUML은 다이어그램 소스를 plantuml.com 서버로 보내 렌더링하므로 기본값이 꺼짐입니다. 그 외 모든 처리는 브라우저 안에서만 이뤄집니다.

## 개발

```bash
npm install
npm run build   # dist/ 생성
npm run watch   # 변경 감지 빌드
npm test        # Chromium에 dist/를 로드해 E2E 검증 (Playwright 필요)
```

- `src/loader.js` — 페이지가 Markdown/폴더인지 판단하고 뷰어 주입 요청
- `src/background.js` — 스크립트 주입, 파일 재읽기, 폴더 목록 조회
- `src/viewer/` — 렌더링, 목차, 폴더 탐색, 스타일
- `src/options/` — 설정 화면(팝업 겸용)
- `src/shared/` — 설정 기본값, 다국어(한국어/영어)

코드를 고친 뒤에는 `npm run build` 후 `chrome://extensions`에서 새로고침 버튼을 누르면 됩니다.
